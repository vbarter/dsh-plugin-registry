常见问题

这是什么注册表？
dsplugin.app 是 DeepSeek Harness（dsh）社区插件目录，收录公开 GitHub 仓库，供浏览、筛选和复制安装命令。本站由社区维护，不是 DeepSeek 官方站点。
dsh.bundle 是什么？
dsh.bundle 是插件仓库根目录 package.json 里的声明，指向一份相对路径的 patch 文件。Manifest 格式检查通过后，本站才会给出 dsh plugin --profile web add github:owner/repo 安装命令。
如何发布插件？
在发布页预检公开 GitHub 仓库，再通过 Issue / PR 提交到 vbarter/dsh-plugin-registry。维护者合并后，dsplugin.app 上的目录才会更新。
「未检查」和「格式检查」是什么意思？
「格式检查通过」表示本站核对过 package.json 里的 dsh.bundle 形态。「未检查」表示条目来自社区目录，本站尚未核对其 Manifest。两者都不是安全审计，也不等于已经做过安装测试。
和 GitHub topic 的区别
官方发现仍是 GitHub dsh-plugin topic。本站是社区目录，有有效 dsh.bundle 才给安装命令。
什么是 dsh 插件市场？
本站是社区目录，不是官方 marketplace；有有效 dsh.bundle 才给安装命令。
dsh plugin registry 是什么？
英文对 dsplugin / 本站的说法，和 dshplugin.app 不是同一站（见 /vs）。
