如何安装 dsh 插件

社区目录只负责展示来源、Manifest 状态和可复制命令。本站不执行安装，也不审计插件安全。

1. 启动 DeepSeek Harness Web

本机需要能跑 Node。用官方 CLI 打开 web profile：

npx @deepseek-ai/dsh web

2. 添加插件

Manifest 格式检查通过后，把 owner/repo 换成仓库地址：

dsh plugin --profile web add github:owner/repo

3. 先看来源，再回仓库确认

复制命令只表示它进了剪贴板。安装前请自己核对 README、依赖和权限。
