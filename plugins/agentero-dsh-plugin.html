agentero-dsh-plugin

agentero-dsh-plugin（科研文献库）是给 DeepSeek Harness（DSH）的社区插件：在本地 Agentero Vault 里搜论文、带出处回答、审批后入库，并把笔记线索交给同会话其他插件。本页只对应目录 id poco-ai/agentero-dsh-plugin。

安装命令

dsh plugin --profile web add github:poco-ai/agentero-dsh-plugin

通用步骤见 /install。

用途

它把本地优先的科研文献库带进 DeepSeek Harness：聊天在中间，论文与 PDF 在侧栏。你可以按主题或链接找论文，让 Agent 引用真实本地出处作答；新文献可走审批后再写入 Vault，讨论结论也能整理成笔记，交给同会话里其它插件接着用。资料留在本机 Agentero Vault，可与 Agentero 桌面端共用同一知识库目录。这是社区插件。

局限与注意

安装必须用上面这一句，从 GitHub 添加 poco-ai/agentero-dsh-plugin。目录里的包名 @poco-ai/agentero-dsh（短名 agentero-dsh）不是安装命令，不要用 npm 安装。配置、CLI、Vault 路径与模型细节以作者仓库为准。本页只介绍用途与安装入口，不是完整教程，也不做安全或版权审计。请仅用于个人学习与研究，论文与素材的版权归权利人所有。
