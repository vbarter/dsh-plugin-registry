ds-bot

ds-bot 是 Fei2411 维护的 DeepSeek Harness 社区插件（Apache-2.0，npm ds-bot，目录来源 curated）。它是长期 Bot 团队：主 Bot、Bot 间消息与群聊；插件包在仓库 ds-bot/ 子目录，不在仓库根。目录 id 是 Fei2411/DS-Bot#ds-bot，目录 stars 约 3903。本页只对应这一包。

安装命令

ds-bot 的安装命令写在页面源码里，不依赖 JavaScript。npm 包名是 ds-bot，作者 Fei2411，仓库 Fei2411/DS-Bot。包在子目录 ds-bot/，命令必须带 #path:/ds-bot。下面这一条只覆盖 web profile。

dsh plugin --profile web add github:Fei2411/DS-Bot#path:/ds-bot

通用步骤见 /install。
