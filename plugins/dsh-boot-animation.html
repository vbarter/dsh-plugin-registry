dsh-boot-animation｜DeepSeek Harness 开机动画插件

dsh-boot-animation 是 lxj5820 的 DeepSeek Harness 开机动画插件（MIT，cordis / dsh.bundle）：全窗口启动短片、片尾交叉溶解进界面，淡入时长与素材池可在「设置 → 插件」调整。目录 id 是 lxj5820/dsh-boot-animation；和其他开机动画分支（如 dsh-boot-animation-pro）不是同一个包，不要装错。

安装命令

dsh-boot-animation 的安装命令写在页面源码里，不依赖 JavaScript。npm 同名包已撤回，不能按其他页那样 add @owner/repo。按仓库 INSTALL.md 路 A，先拿到本地目录再交给 CLI：

git clone https://github.com/lxj5820/dsh-boot-animation.git
dsh plugin --profile web add ./dsh-boot-animation

路 A 的参数是解压（或 clone）出来的目录，不是 GitHub 包名。桌面版 profile 叫 desktop，这条命令不能直接改它。桌面版用 INSTALL.md 路 B（Windows tools/install.ps1）或路 C（macOS / Linux tools/install.sh）。装完重启一次 DSH。

仓库：https://github.com/lxj5820/dsh-boot-animation

常见问题

这页是插件目录或完整安装教程吗？
不是。本页只介绍 lxj5820/dsh-boot-animation 这一包。浏览更多插件回 /，安装步骤与排查见 /install。
dsh-boot-animation 和 dsh-boot-animation-pro 有什么不同？
不是同一个仓库、也不是同一个包。本页对应 lxj5820/dsh-boot-animation。目录里还有别家开机动画分支（例如 Yiheng-guo/dsh-boot-animation-pro、NativeDog1/dsh-boot-animation），作者和安装方式可能不同。搜「开机动画」时先对一下作者与 slug，避免装错。
npm 包名能直接 dsh plugin add 吗？
不能按其他页那种 npm / github:owner/repo 习惯硬套。按仓库 INSTALL：先 git clone https://github.com/lxj5820/dsh-boot-animation.git，再 dsh plugin --profile web add ./dsh-boot-animation（参数是本地目录）。桌面版用 INSTALL 里的 Windows / macOS·Linux 脚本路径，装完重启一次 DSH。
装完能改片子和淡入吗？
可以。在 设置 → 插件 → 启动动画 里调总开关、声音、点击直接进入、淡入时长、进入方式（片尾交叉溶解 / 放完再淡 / 点击才进）和素材池。改设置后刷新页面即可；改 entry.js 一类代码才需要重启。
这页是完整安装教程吗？
不是。本页只介绍 lxj5820/dsh-boot-animation。浏览更多插件回 /，安装步骤与排查见 /install。
