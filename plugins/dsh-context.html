dsh-context｜DeepSeek Harness 插件

dsh-context 是 DeepSeek Harness 的社区插件（Apache-2.0，npm dsh-context@0.69.1，GitHub 2047 stars），在 web/桌面端里给出会话上下文的统计、构成、趋势和事件记录。目录 id 是 bowenliang123/dsh-context。安装：dsh plugin --profile web add dsh-context。本页只对应这一包。

安装命令

dsh-context 的安装命令写在页面源码里，不依赖 JavaScript。web 或桌面端：Add plugin 搜 dsh-context 安装。CLI：

dsh plugin --profile web add dsh-context

更新：

dsh plugin --profile web update dsh-context@latest

然后 dsh web。npm 包是 dsh-context@0.69.1。通用步骤见 /install。

仓库：https://github.com/bowenliang123/dsh-context

五个入口

  • Context Insights 页：侧栏一级面板，跨会话看 token/费用、7 天用量、活跃热力图、会话卡片。
  • Context 标签：单会话仪表盘，含统计、当前上下文构成、逐请求趋势、上下文浏览器、事件、文件活动。
  • Fleet 标签：当前 agent、父级和子 agent 的卡片。
  • 右侧栏 Context 面板：同一仪表盘放在聊天旁。
  • /context 命令：弹窗显示当前构成和上下文浏览器。

局限与风险

  • 分类数字是估算，和 dsh 内置 token 计量用同一套启发式；趋势详情另列服务端实际值。
  • 兼容 @deepseek-ai/dsh 0.1.7-rc.2+；界面中英文。
  • System Prompt 前/后缀设置会作用于所有会话和子 agent，改动从下一轮生效。

常见问题

dsh-context 能看到什么？
五个入口：Context Insights 页是侧栏一级面板，跨会话看 token/费用、7 天用量、活跃热力图和会话卡片；Context 标签是单会话仪表盘，含统计、当前上下文构成、逐请求趋势、上下文浏览器、事件和文件活动；Fleet 标签给出当前 agent、父级和子 agent 的卡片；右侧栏 Context 面板把同一仪表盘放在聊天旁；/context 命令用弹窗显示当前构成和上下文浏览器。
怎么安装/更新？
在 Add plugin 里搜 dsh-context 安装。CLI 执行 dsh plugin --profile web add dsh-context。更新执行 dsh plugin --profile web update dsh-context@latest。然后 dsh web。
数字准吗？
分类数字是估算，和 dsh 内置 token 计量用同一套启发式。趋势详情另列服务端实际值。
在哪改设置？
Plugins → dsh-context → Configuration。本页不是完整教程。浏览更多插件回 /，安装步骤见 /install。
