dsh-harnmem

dsh-harnmem 是 ys118 维护的 DeepSeek Harness（DSH）记忆插件（MIT，npm dsh-harnmem@0.4.0）。本页只对应目录 id ys118/harnmem#packages/dsh-harnmem（上游 ys118/harnmem 的 packages/dsh-harnmem），不是 harnmem-monorepo、@harnmem/cli 或 pi-harnmem。

安装命令

dsh plugin --profile desktop add dsh-harnmem

通用步骤见 /install。npm 钉在 dsh-harnmem@0.4.0。

用途

占位页。HarnMem 给 DSH 提供记忆：稳定热索引注入、记忆工具、会话结束抽取，以及只读记忆浏览面板。细节以作者 README 为准，正文以后替换。

可安装身份是 npm 包 dsh-harnmem。源码在上游 https://github.com/ys118/harnmem 的 packages/dsh-harnmem。同仓库的 harnmem-monorepo（目录行无安装命令）、@harnmem/cli、pi-harnmem 不是这一包，本站不为它们单独开页。
