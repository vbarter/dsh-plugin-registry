dsh-ios

dsh-ios（iOS 模拟器与真机流）是给 DeepSeek Harness（DSH）的社区插件：在会话里接入 iOS Simulator，以及经 USB 连接的 iPhone 真机画面，用于构建、运行、按无障碍或 OCR 操作界面，并在侧栏预览。本页只对应目录 id ZSeven-W/dsh-ios。

安装命令

dsh plugin --profile web add github:ZSeven-W/dsh-ios

通用步骤见 /install。

用途

它把 iOS Simulator，以及经 USB 连接的 iPhone 真机，接到 DeepSeek Harness 会话里：可以启动设备、构建并运行应用，按无障碍身份或 OCR 文字操作界面，并在侧栏实时预览、点按或拖拽。这是社区插件，需要在已安装 Xcode 的 macOS 上使用。

局限与注意

安装必须用上面这一句，从 GitHub 添加 ZSeven-W/dsh-ios。目录包名 @zseven-w/dsh-ios 不是安装命令，不要用 npm 或短式包名安装。配置、真机条件与工具细节以作者仓库为准。本页只介绍用途与安装入口，不是完整教程，也不做安全或版权审计。请仅用于个人学习与研究；内容与素材的版权归权利人所有。
