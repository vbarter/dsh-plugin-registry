dsh-ops｜DeepSeek Harness 插件

dsh-ops 是 T-Auto 维护的 DeepSeek Harness 社区插件（MIT，npm dsh-ops）。它以提高 token 效率为主要目标：提供一组 ops 系列工具，并可选隐藏部分官方工具，改动面小、侵入性低，便于和其他插件一起用。本页只对应目录 id T-Auto/dsh-ops 这一包。

安装命令

dsh-ops 的安装命令写在页面源码里，不依赖 JavaScript。npm 包名是 dsh-ops，作者 T-Auto。下面这一条只覆盖 web profile。

dsh plugin --profile web add github:T-Auto/dsh-ops

通用步骤见 /install。

仓库：https://github.com/T-Auto/dsh-ops

为什么需要它

默认工具返回偏冗长时容易把上下文和费用撑大。dsh-ops 用更紧凑的返回、按需加载的高级能力，以及（在支持的模式下）结构化结果，来压低常见场景的 token 消耗。

能力

  • Windows bash（仅 Windows）：可启用与 dsh 原生 bash 行为一致的 ops_bash，并可选禁用 PowerShell，减少壳层切换带来的误差。
  • 渐进式工具加载：启用 DSH 预留的 tools_addition，把 PDF/Word 读取、大批量文件修改等能力做成按需加载，避免系统提示词长期膨胀。
  • Native 模式：提供返回更紧凑、带行号、错误回馈更清楚的工具，减轻报错循环。
  • PTC 模式：提供返回结构化 JSON 的工具，降低在 PTC 下写 TypeScript 的负担。

局限与注意

  • 完整安装还有桌面端、TUI 等 profile。本页安装命令只覆盖 web profile 的 github:T-Auto/dsh-ops 写法；其他 profile 和 npx / 插件市场路径见作者 README，本站不展开。
  • npm registry 的 license 字段可能显示 MIT AND Apache-2.0（与可选 Windows bash 载荷等有关）。当前源码主体按仓库 LICENSE 为 MIT。以仓库与 README 为准。
  • 本页不是完整教程，也不做安全审计。
