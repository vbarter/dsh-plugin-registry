安装命令

dsh-plugin-security 的安装命令写在页面源码里，不依赖 JavaScript。目录安装字段是 GitHub 源；npm 同名包当前是 dsh-plugin-security@0.4.7，仓库 README 也写了 @latest。

dsh plugin --profile web add github:dushaobindoudou/dsh-plugin-security
dsh plugin --profile web add dsh-plugin-security@0.4.7

跟 README 走最新版时，把版本换成 dsh-plugin-security@latest。装完重启正在跑的宿主，打开 Settings → Security Gate。其他已有 profile 把 web 换成对应名字。

仓库：https://github.com/dushaobindoudou/dsh-plugin-security

dsh-plugin-security 是社区插件，不是 DeepSeek 官方内置能力。它核对已装依赖公告，做语境审读，并支持可撤销处置。本页只介绍 dushaobindoudou 这一包；目录里的 *-security-review 和 *-security-audit 作者和仓库都不同，不要装错。本站不审计、不替你装。更多插件回 目录，安装步骤见 /install。
