dsh-providers-hub

dsh-providers-hub（多服务账号中枢）是给 DeepSeek Harness（DSH）的社区插件：在 Jet Hub 里登录并管理多家 AI 编程服务账号，支持多账号池与凭据静默续期，并把这些渠道的模型接到 DSH 模型选择器。本页只对应目录 id iJetLi/dsh-providers-hub。

安装命令

dsh plugin --profile web add github:iJetLi/dsh-providers-hub

通用步骤见 /install。

用途

它把多家 AI 编程服务的账号收进同一个 Jet Hub 面板：登录、查看状态、凭据续期和积分领取都在设置页完成，不注册斜杠命令。同一服务可以登录多个账号做成账号池，按可用性自动选号；到期前会尝试静默刷新凭据。登录成功后，可在 DSH 模型选择器里选用对应渠道的模型，也可用聚合路由按临期额度自动挑渠道，或把已登录账号通过本机 OpenAI 兼容网关供给其它客户端。这是社区插件。

局限与注意

安装必须用上面这一句，从 GitHub 添加 iJetLi/dsh-providers-hub。仓库 README 里还有旧包名升级说明与其它安装渠道，那些都不是本页的安装命令；短式包名、path 形式、其它 profile 和 npm 安装也不是。本包曾用名 dsh-codearts-auth 同样不是安装命令。配置、渠道与网关细节以作者仓库为准。本页只介绍用途与安装入口，不是完整教程，也不做安全或版权审计。请仅用于个人学习与研究，并遵守各服务提供方的服务条款；内容与素材的版权归权利人所有。
