dsh-scriptor

dsh-scriptor 是面向 DeepSeek Harness（DSH）的社区插件（npm @linfengqaqtat/dsh-scriptor，GPL-3.0-only），把长篇网文写作工作台接到 DSH。本页只对应目录 id lingfengQAQ/webnovel-writer#packages/bundle 这一包（上游仓库 lingfengQAQ/webnovel-writer 的 packages/bundle）。

安装命令

dsh plugin --profile web add @linfengqaqtat/dsh-scriptor

通用步骤见 /install。

用途

它面向连载与长篇中文网文创作，在 DSH 侧提供写作辅助工作流（大纲、章节、持续连载等细节以作者文档为准）。可安装身份是 npm 作用域包 @linfengqaqtat/dsh-scriptor；源码在上游 lingfengQAQ/webnovel-writer 的 packages/bundle，并不是独立的 linfengqaqtat/dsh-scriptor GitHub 仓库。

对 DSH 版本的要求以 npm 与作者 README 为准，本页不钉具体 rc。更完整的功能说明、桌面端添加插件与升级备份，见上游仓库与作者站点；本页只做用途说明与唯一安装入口。

局限与注意

安装必须用上面的 npm 作用域命令，不要写 github 冒号路径。本页不是完整教程，也不做安全审计。
