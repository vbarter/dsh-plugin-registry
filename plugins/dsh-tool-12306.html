dsh-tool-12306｜DeepSeek Harness 查票插件

dsh-tool-12306 是 DeepSeek Harness 的 12306 查询插件（MIT，npm dsh-tool-12306@0.1.6）。直达车次与余票、两程中转、经停站都在这一页完成；不登录、不购票、不抢票。仓库 zanedonkey/dsh-tool-12306。查票场景以本页为准，不开单独品类页。

安装命令

dsh-tool-12306 的安装命令写在页面源码里，不依赖 JavaScript。需要 Node.js 22.19+（22 系列）或 24+。

桌面端：插件 → 添加插件，输入下面这一行，装完点立即启用。

dsh-tool-12306@0.1.6

CLI（profile rail）：

dsh plugin --profile rail add dsh-tool-12306@0.1.6

仓库：https://github.com/zanedonkey/dsh-tool-12306

能查什么

装好后在 Harness 里直接自然语言提问即可，无需另起 MCP Server。典型用法：

  • 查明天北京到上海的高铁，只看有二等座的，最多列出 5 趟。
  • 查明天下午两点以后上海虹桥到杭州东的高铁。
  • 查明天深圳到拉萨的中转，第一程二等座、第二程硬卧，两程都要有票。
  • G1 次列车明天经过哪些车站？

注册工具包括：12306_query_tickets（直达/余票）、12306_query_transfer（中转）、12306_train_route（经停）、12306_plugin_info（版本诊断）。

局限与风险

社区查票插件，不是 DeepSeek 官方能力，也不是 12306 官方客户端。不提供登录、购票、抢票或支付；余票与价格以官方实时信息为准。需要 Node.js 22.19+（22 系列）或 24+。本站不审计、不替你装。更多插件回 /，安装步骤见 /install。

常见问题

这页是插件目录或完整安装教程吗？
不是。本页只介绍 dsh-tool-12306 的查票与安装。浏览更多插件回 /，安装步骤与排查见 /install。
dsh-tool-12306 能查什么？
直达车次、时刻与余票；城市/车站解析与席别筛选；两程中转（同站/跨站换乘、等待时间与席别组合）；列车经停站与沿途区间。查票场景挂本页，不另开 /c/*。
能购票或抢票吗？
不能。本插件只查询，不登录、不读 Cookie、不存账号密码，也不绕过验证码。需要购票请走 12306 官方渠道。
还要单独起 MCP Server 吗？
不用。它是 Harness 原生插件，装完自动注册工具；基于开源 12306 查询实现优化，不需要额外 MCP 进程。自然语言查询需先在 Harness 里配置可用模型。
桌面端和 CLI 怎么装？
桌面端：插件 → 添加插件，输入 dsh-tool-12306@0.1.6，装完点立即启用。CLI：dsh plugin --profile rail add dsh-tool-12306@0.1.6。升级时先卸旧版再装新版，并完全退出 Harness（含托盘）后重开。细节与排查见 /install。
