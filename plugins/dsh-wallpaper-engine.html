dsh-wallpaper-engine

dsh-wallpaper-engine（Wallpaper Engine 背景接入）是给 DeepSeek Harness（DSH）的社区插件：把本机 Wallpaper Engine 里的 Scene、Web 或视频内容，铺到 DSH 网页会话界面背后使用。使用前需要本机已有 Wallpaper Engine 的内容库。本页只对应目录 id elysia395/dsh-wallpaper-engine。

Manifest 状态未检查
版本暂无
最近更新暂无

安装命令

dsh plugin --profile web add github:elysia395/dsh-wallpaper-engine

通用步骤见 /install。

用途

它读取本机已有的 Wallpaper Engine 内容库，把其中的 Scene、Web 或视频铺到 DeepSeek Harness 网页会话界面背后，并可在设置里筛选、轮播或调整显示。这是社区插件，需要本机已准备好 Wallpaper Engine 的内容；本页不是该软件的产品页，也不做通用的 DSH 界面美化目录。

局限与注意

安装必须用上面这一句，从 GitHub 添加 elysia395/dsh-wallpaper-engine。仓库 README 里还有短式包名、其它 profile 与源码安装方式，那些都不是本页的安装命令；不要用短式包名、npm 或其它 profile 安装。配置、内容库路径与兼容细节以作者仓库为准。本页只介绍用途与安装入口，不是完整教程，也不做安全或版权审计。请仅用于个人学习与研究；内容与素材的版权归权利人所有。
