Plugin · dsh-web-ui

dsh-web-ui｜DeepSeek Harness Web UI 插件

dsh-web-ui 是 DeepSeek Harness Web UI 插件合集：任务看板、git 图、右侧面板与皮肤。仓库 zhu1090093659/dsh-web-ui。

安装命令

dsh-web-ui 的安装命令写在页面源码里，不依赖 JavaScript：

dsh plugin --profile web add @linxin666/dsh-web-ui-all

包名是 @linxin666/dsh-web-ui-all，源码在 zhu1090093659/dsh-web-ui。先看来源和 Manifest，再回仓库确认依赖。

仓库：https://github.com/zhu1090093659/dsh-web-ui
