eac-design-world

eac-design-world（EAC design world）是给 DeepSeek Harness（DSH）的社区插件：在本地完成视频制作与设计，支持多轨剪辑、模板与设计体系、原生预览和真实文件导出。本页只对应目录 id Ebony-Vinyl/EAC-design-world。

Manifest 状态未检查

最近更新暂无

安装命令

dsh plugin --profile web add github:Ebony-Vinyl/EAC-design-world

通用步骤见 /install。

用途

它把本地视频制作与设计带进 DeepSeek Harness：可在多轨时间线上编排片段，选用模板与设计体系，在侧栏做原生预览，并把成片、字幕或设计源文件导出到本地。也可以在本机单独打开工作台。剪辑与导出由插件自己完成。这是社区插件。

局限与注意

安装必须用上面这一句，从 GitHub 添加 Ebony-Vinyl/EAC-design-world（路径大小写需与上面一致）。仓库 README 里还有发布包与其它安装渠道，那些都不是本页的安装命令；短式包名、其它 profile 和 npm 安装也不是。配置、模板与导出细节以作者仓库为准。本页只介绍用途与安装入口，不是完整教程，也不做安全或版权审计。请仅用于个人学习与研究，并遵守素材、模板与第三方服务的许可与条款；内容与素材的版权归权利人所有。
