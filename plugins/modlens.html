Plugin · ModLens

ModLens｜DeepSeek Harness vision 插件

ModLens 是 DeepSeek Harness vision 插件：给纯文本模型补上视觉证据（OCR、版面、语义）。仓库 liustack/modlens。

安装命令

ModLens 的安装命令写在页面源码里，不依赖 JavaScript：

npx -y @deepseek-ai/dsh plugin --profile web add @liustack/modlens@3.16.7

粘贴图片，输出结构化 JSON 证据。安装前请阅读仓库 README；本站不执行安装测试。

仓库：https://github.com/liustack/modlens
