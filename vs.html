Compare · dsplugin vs dshplugin

dsplugin.app 和 dshplugin 有何不同

dsplugin.app 是社区维护的 DeepSeek Harness 插件目录。搜索「dshplugin」时也常指向同一类站点；请以本页的来源、Manifest 和安装命令为准。

一句话

dsplugin.app 收录公开 GitHub 仓库，先看来源和 Manifest 状态，有有效 dsh.bundle 才给安装命令。它不是 DeepSeek 官方站，也不替代 GitHub dsh-plugin topic。

和「dshplugin」这个词

dshplugin 是常见拼写和检索词，可能指向未经验证的镜像、旧域名或口头简称。本站的规范地址是 https://dsplugin.app/。对比时请核对：是否声明社区身份、是否只在有效 Manifest 后给出安装命令、提交是否走公开 GitHub Issue。

本站会做什么、不会做什么

  • 会：按来源与 Manifest 筛选，复制安装命令，走 GitHub 审核发布。
  • 不会：冒充官方、编造下载量或评分、替你执行安装或安全审计。
