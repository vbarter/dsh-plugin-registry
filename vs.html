Compare · dsplugin vs dshplugin

dsplugin.app 和 dshplugin 有何不同

三家都是社区目录，都不是 DeepSeek 官方。官方发现仍是 GitHub dsh-plugin topic。搜「dshplugin」偶尔也会进到我们，以本页对照为准。

dsplugin.app（我们）

中文安装/发布路径。先看来源和 Manifest，有有效 dsh.bundle 才给 dsh plugin add。提交：预检 → GitHub Issue → vbarter/dsh-plugin-registry。

dshplugin.app

英文指南更厚，带安全/兼容信号和源码分析，适合要比对情报的人。

dshplugin.world

静态可抓的短名单，人工核对过 README 和安装命令，不是全量 topic 倾销。

不会做什么

不会：冒充官方、编下载量、替你装或做安全审计。

常见问题

dsplugin.app、dshplugin.app、dshplugin.world 怎么分？
三家都是社区目录，都不是 DeepSeek 官方。本站（dsplugin.app）偏中文路径，先看来源与 Manifest 状态；dshplugin.app 英文指南更厚、带安全/兼容信号；dshplugin.world 是静态短名单。认站以本页对照表为准。
近形域名怎么避免认错？
dsplugin 与 dshplugin 只差一个字母。搜到近形域名时先回本页看三家对照，再点站；规范域名是 dsplugin.app。本站不冒充官方、不替装、不做安全审计。
搜 dsplugin 会进 dshplugin.app 吗？
近形域名常见；对照本页三家，规范站是 dsplugin.app。
